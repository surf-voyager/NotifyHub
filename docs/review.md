# 多轮自省与执行门槛

第一轮审查配置迁移：全部机器路径、topic 和密钥位于 Git 忽略文件。相对路径从配置文件定位，clone 后重建独立环境和通知身份。
第二轮审查网络协议：方法与内容明确，HMAC、时间窗口、UTF-8 大小上限、队列上限、持久化去重；重启标记中断，不重复播报。
第三轮审查代理与资源：edge-tts 的 proxy=None 仍读取环境代理，改用独立进程清除代理与 NO_PROXY=*。ntfy 明确关闭继承。临时音频等待播放结束才删除，失败与停止均清理，Job Object 约束进程树。
第四轮审查 Windows 生命周期：用户会话托盘，登录自启动可切换，互斥锁防重复；先校验配置和密钥再重启；Windows 通知身份在部署阶段注册。
第五轮审查实现证据：中文管道编码问题由 UTF-8 文件生成和真实中文测试修复。非有限时间戳拒绝。环境、认证、队列、清理和迁移测试通过后再执行正式部署。

执行门槛：核心测试全部通过，Windows API 可用，ntfy 与 edge-tts 在无效代理条件下真实直连成功，Git 内容无本机设置。门槛达到后自动进行全新 clone、安装、通知注册、启动及本机验收。
实施信心是基于这些证据的工程判断，不表示外部服务永不失败。外部主机实测和用户是否实际看见/听见通知应分别记录，不能由 API 返回值替代。
